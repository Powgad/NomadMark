# NomadMark 横屏布局设计方案

## 1. 设计目标

为 NomadMark 应用设计一套适合横屏使用的布局，保持功能完整性的同时优化横屏体验。

## 2. 设计原则

1. **保持功能一致**：所有竖屏功能在横屏下同样可用
2. **优化空间利用**：利用横屏宽度优势，弥补高度不足
3. **复用现有代码**：最大化复用现有组件和逻辑
4. **渐进式实现**：分阶段实现，优先核心功能

## 3. 布局结构调整

### 3.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        顶部工具栏 (双行设计)                   │
├─────────────────────────────────────────────────────────────┤
│  主内容区域 (横屏优化：左右分屏替代上下分屏)                  │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 顶部工具栏：双行设计

**现状问题**：竖屏下12个按钮排在一行，横屏高度减少时占用过多空间

**横屏方案**：

```
┌─────────────────────────────────────────────────────────────┐
│ [返回] [目录] [打开] │      文件名      │ [保存] [设置]     │ 第一行
├─────────────────────────────────────────────────────────────┤
│ [预览] [修订] [搜索] [分屏] [撤销] [重做] [快捷栏]           │ 第二行
└─────────────────────────────────────────────────────────────┘
```

**按钮分组**：
- **第一行**：导航类 + 核心操作
  - 导航：返回、目录、打开
  - 信息：文件名（居中）
  - 设置：保存、按键设置
- **第二行**：编辑功能类
  - 模式切换：预览、修订、分屏
  - 编辑操作：撤销、重做、搜索、快捷栏

**高度调整**：
- 第一行：`48dp`（略减小）
- 第二行：`48dp`
- 总高度：`96dp`（相比竖屏 56dp 增加，但横屏高度减少影响不大）

### 3.3 主内容区域

#### 3.3.1 编辑模式 / 预览模式

保持不变，内容区域宽度增加，显示更多内容列数。

#### 3.3.2 分屏模式：左右分屏

**现状问题**：竖屏下是上下 6:4 分配

**横屏方案**：左右 1:1 分配

```
┌─────────────────────────────────────────────────────────────┐
│                    预览区 (左, 50%)                          │
│                                                              │
│                     [竖分隔线]                                │
│                                                              │
│                    编辑区 (右, 50%)                          │
└─────────────────────────────────────────────────────────────┘
```

**布局结构**：
```xml
<LinearLayout
    android:orientation="horizontal"
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <!-- 左侧预览区 -->
    <ObservableScrollView
        android:layout_width="0dp"
        android:layout_height="match_parent"
        android:layout_weight="1">

        <TextView ... />
    </ObservableScrollView>

    <!-- 分隔线 -->
    <View
        android:layout_width="2dp"
        android:layout_height="match_parent"
        android:background="#000000" />

    <!-- 右侧编辑区 -->
    <ObservableScrollView
        android:layout_width="0dp"
        android:layout_height="match_parent"
        android:layout_weight="1">

        <EditText ... />
    </ObservableScrollView>
</LinearLayout>
```

### 3.4 搜索栏

保持横向布局不变，横屏宽度增加时更宽松。

### 3.5 目录侧边栏

**现状问题**：占 2/3 宽度，横屏下可能过宽

**横屏方案**：调整为 50% 宽度

```
┌─────────────────────────────────────────────────────────────┐
│     目录列表 (50%)      │      空白区域 (50%)               │
└─────────────────────────────────────────────────────────────┘
```

### 3.6 底部快捷栏

**现状**：HorizontalScrollView 横向滚动

**横屏优化**：
- 横屏时宽度增加，大部分按钮可以一次性显示
- 考虑改为两行布局以充分利用空间

```
┌─────────────────────────────────────────────────────────────┐
│ [**B**] [*I*] [H+] [H-] [`代码`] [```] [链接] [图片]        │ 第一行
├─────────────────────────────────────────────────────────────┤
│ [- 列表] [> 引用] [表格] [---] [∑]                          │ 第二行
└─────────────────────────────────────────────────────────────┘
```

## 4. 尺寸调整

### 4.1 新建 `values-land/dimens.xml`

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <!-- 横屏工具栏高度 -->
    <dimen name="toolbar_row_height">48dp</dimen>
    <dimen name="toolbar_height">96dp</dimen>

    <!-- 横屏底部快捷栏高度（两行） -->
    <dimen name="bottom_toolbar_height">80dp</dimen>

    <!-- 横屏内容区域内边距 -->
    <dimen name="content_padding_horizontal">24dp</dimen>
    <dimen name="content_padding_vertical">16dp</dimen>

    <!-- 横屏文字大小调整（考虑更宽的显示区域） -->
    <dimen name="text_size_small">12sp</dimen>
    <dimen name="text_size_normal">14sp</dimen>
    <dimen name="text_size_medium">16sp</dimen>
</resources>
```

### 4.2 字体大小

横屏时内容宽度增加，可以考虑：
- 正文保持 `16sp`
- 表格、代码块可能显示更多列
- 标题可适当增大以充分利用空间

## 5. 实现方案

### 5.1 目录结构

```
platforms/android/app/src/main/res/
├── layout/
│   └── activity_editor.xml          (竖屏布局，现有)
└── layout-land/
    └── activity_editor.xml          (横屏布局，新建)
```

### 5.2 实现步骤

#### 第一阶段：基础横屏布局

1. **创建 `layout-land/activity_editor.xml`**
   - 复制竖屏布局
   - 调整顶部工具栏为双行
   - 调整分屏层为左右分屏

2. **创建 `values-land/dimens.xml`**
   - 定义横屏专用尺寸

3. **测试基础功能**
   - 旋转设备测试布局显示
   - 验证各功能在横屏下正常工作

#### 第二阶段：细节优化

1. **优化目录侧边栏宽度**
2. **优化底部快捷栏布局**
3. **调整内边距和间距**

#### 第三阶段：特殊场景处理

1. **乐谱渲染横屏适配**
2. **搜索栏横屏优化**
3. **键盘弹出时的布局调整**

## 6. 兼容性考虑

### 6.1 Android 版本

- Android API 21+（5.0+）完全支持 layout-land

### 6.2 Supernote 设备

需要确认：
- [ ] 设备是否允许横屏旋转
- [ ] 墨水屏横屏刷新率是否影响体验
- [ ] 键盘在横屏下的位置和大小

### 6.3 状态保持

由于 `configChanges` 已设置，旋转时：
- Activity 不会重建
- 所有状态（文本、光标位置、模式等）自动保持
- 系统会自动应用对应的布局文件
